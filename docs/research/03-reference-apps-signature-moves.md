# Reference apps: signature UI moves worth borrowing (verified Sept 2026)

Strongest verified detail: Opal, WHOOP, Oura, Gentler Streak, Focus Friend, Ebb, Duolingo, Bevel, Finch. Thin/unverified: Wakeout, Sunlitt, Lumy, Strava 2025 specifics.

1. **Endel** — one-decision home (pick a mode, audio starts); per-mode generative visual (drifting particle field on black) that responds to audio, time, weather, heart rate; controls shrink to near-invisible so the visual dominates. *Borrow:* zero-choice start + ambient visual driven by the user's own data.
2. **Opal** — near-black ground with glow semantics per feature; 3D milestone gems with dedicated unlock animation and touch "wiggle"; 24-step onboarding that quantifies lifetime phone use, then a fist-bump commitment animation before the paywall. *Borrow:* one 3D reward object; a commitment gesture before asking for anything.
3. **Rise Sleep** — the signature artifact is a day-long predicted energy curve with labeled windows (grogginess, peak, afternoon dip, wind-down, melatonin window); sleep debt as one number. *Borrow:* a predicted daily curve that says when to push and when to rest.
4. **Balance** — two-phase goal ranking in onboarding (select, then drag to rank); contextual permission prompts inside the relevant step; nightly one-tap rating that visibly changes tomorrow's session; Skills view instead of streak. *Borrow:* rating that changes the next session; skills over streaks.
5. **Structured** — vertical timeline where block height is proportional to duration; icon + color per task; inbox-first; overlap alerts. *Borrow:* coach-suggested actions dropped as blocks between existing commitments.
6. **Bevel** — four headline scores as "one honest daily read"; themed backgrounds; **morphing face mood slider**; 34-step onboarding that demonstrates instead of asks; AI replies cite sources. *Borrow:* morphing slider; citations in coach replies.
7. **Oura (Oct 2025 redesign)** — five tabs → three; a single "one big thing" card that changes across the day; color as status; metrics vs personal baseline bands; nature scenery replaces boxed cards ("no longer feels like everything's separated by tape"). *Borrow:* one hero insight per moment; baseline bands not absolute numbers.
8. **WHOOP** — strict green/yellow/red semantic system, no decorative accents; ~72pt numerals; three-tier progressive disclosure (tile → trend → raw) with spatially continuous transitions; near-black for early-morning readability. *Borrow:* three-tier disclosure; strict status vocabulary.
9. **Gentler Streak** — Activity Path band (in/above/below optimal range) phrased as "Path of Effort / Path of Rest"; mascot annotates charts; copy rule "supportive but not cheesy, motivating but not fake-hyped"; 2025 redesign 4 tabs → 3. *Borrow:* a readiness band that licenses rest; a voice that annotates data.
10. **Waterllama** — outlined character fills with liquid toward the daily goal; particles per beverage; share-designed celebration screen; Liquid Glass on iOS 26. *Borrow:* progress as a physical volume.
11. **Bloom** — the logo (a 3D trefoil) is the breathing pacer; mascot derived from the check-in emoji set. *Borrow:* logo as functional element.
12. **Finch** — egg-to-bird progression; bird's energy is the visible consequence of your check-in; zero punishment on skipped days ("gentle parenting" notifications); 4.9★ (749K). *Borrow:* consequence-visible companion; forgiving copy.
13. **Focus Friend** — the Bean's animated room is the home; it knits only while your timer runs; Live Activity; voice: "Until we bean again." *Borrow:* companion visibly working during your focus block, persisted to the lock screen.
14. **Headspace Ebb** — gradient blob whose motion is modeled on a lava lamp ("emotions ebb and flow"), designed to feel listening "but not too happy"; always labeled as AI; exit-and-delete anytime; crisis resources in view; Jumpstart prompts ("I need a pep talk"). *Borrow:* slow amorphous avatar; pre-written prompts for hard moments; transparency rules.
15. **Calm** — one fixed scenic backdrop carried from icon to home becomes the brand; player with no scrubbing so sessions can't be skipped. *Borrow:* fixed scene as brand; remove the skip.
16. **Tide** — full-bleed nature photography per scene; daily quote card designed to be screenshotted. *Borrow:* share-designed daily card.
17. **Apple Journal** — Suggestions sheet seeds entries from your own photos/workouts/places, each with a prompt; Insights with streaks and calendar grid; State of Mind logging. *Borrow:* prompts seeded from the user's own day.
18. **Apple Fitness+** — live metric overlay; Burn Bar compares effort to everyone who did the workout; named plan presets ("Stay Consistent", "Push Further"). *Borrow:* plan presets that describe intent, not volume.
19. **Strava** — Athlete Intelligence: a short AI paragraph atop each logged activity explaining what it meant; refreshed Progress tab (Aug 2026). *Borrow:* one-paragraph AI meaning atop each logged action.
20. **Duolingo (Feb 2026 core tabs refresh)** — type system cut to a minimal set of styles; whitespace instead of containers; streak widget shows exactly two facts (streak length, done/not) and Duo's illustration degrades toward "desperate" as midnight nears; half of widget users hold 6‑month+ streaks. *Borrow:* two-fact widget; mascot mood reflects risk.
21. **Sunlitt / Lumy (unverified)** — sun path arc over a compass; full-screen gradient matching the sky's current color; golden/blue-hour markers; large rounded numerals. *Borrow:* time-of-day gradient as ambient status; "the whole screen is the data."
22. **Sky Guide v12** — Liquid Glass UI; cinematic time controls to scrub past/future; 120 fps; soundtrack. *Borrow:* a time scrubber that animates the user's trajectory forward and back.
23. **Wakeout (unverified)** — flat-illustrated looping characters demonstrating micro-actions on saturated solid backdrops. *Borrow:* illustrated loops instead of video for micro-actions.
